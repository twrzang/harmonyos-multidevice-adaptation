# HarmonyOS 一多适配 Skill

检查和适配 ArkUI 应用在手机、折叠屏和平板上的布局，包括窗口断点、导航分栏、内容栅格，以及旋转、折展和分屏时的状态连续性。

## 安装

```bash
npx skills add twrzang/harmonyos-multidevice-adaptation --skill harmonyos-multidevice-adaptation
```

## 使用示例

> 用 harmonyos-multidevice-adaptation 检查项目的任务列表和详情页。重点看折叠展开、平板分屏时的栅格列数，以及编辑中的内容是否保留。
